JLWWWC SLT — Updated Starter App

CONTENTS
- index.html: responsive dashboard and navigation prototype
- assets/jlwwwc-logo.png: church logo supplied by the user
- manifest.webmanifest: installable web app metadata
- sw.js: basic offline shell cache

NEW IN THIS VERSION
- Uses the official JLWWWC Southern Leyte logo supplied in this conversation.
- Adds a Prayer Meeting Prayer List to the dashboard.
- Prayer requests can be added and removed while the page is open.

HOW TO PREVIEW
1. Extract this ZIP.
2. Keep the assets folder beside index.html.
3. Open index.html in a modern browser to preview the dashboard.
4. For Android installation, host the files on an HTTPS website, open it in Chrome, then choose Install app / Add to Home screen.

IMPORTANT PRIVACY AND SECURITY
This is still a front-end prototype. It does NOT yet have real login, user roles, database synchronization, backups, or secure storage. Prayer list entries exist only in the current open page session and are not saved. Do not enter real personal, pastoral, or financial information until secure authentication and protected storage are implemented. Free hosting/database tiers have limits and may change.
